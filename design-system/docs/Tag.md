Monospace tech chip for stack labels like "React" or "RAG". `light` for cream/white surfaces (default), `dark` for the terminal surface, `muted` for low emphasis.

```tsx
import { Tag } from 'civic-ui'

<Tag>React</Tag>
<Tag tone="muted">Python</Tag>
<Tag tone="dark">Ollama</Tag>
```
