The lime square that frames a single icon. The icon (children) scales to half the box. Used standalone or as the leading mark in FeatureItem and ProjectCard. Tones: `lime` (default), `sky`, `purple`. Sizes: `sm`/`md`/`lg`.

```tsx
import { IconBox } from 'civic-ui'

<IconBox tone="lime"><ZapIcon /></IconBox>
<IconBox tone="sky" size="lg"><GlobeIcon /></IconBox>
```
