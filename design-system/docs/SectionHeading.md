Section title block: an optional mono kicker, a heavy display headline, and an optional subtitle — the site's typographic scale and tracking. Modifiers: `center`, `gradient` (lime→emerald text clip), `size` (`sm`/`md`), and `level` (the heading tag).

```tsx
import { SectionHeading } from 'civic-ui'

<SectionHeading
  kicker="◆ Open-source civic tech"
  title="AI tools for the public good"
  subtitle="Free, transparent, community-owned software."
/>
```
